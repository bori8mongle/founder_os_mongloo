# 페블링 이용약관·개인정보 기준선

이 문서는 법률 자문이 아니라, 공개 문서·App Store 표시·현재 코드·개발 계획
사이의 정합성을 제품 관점에서 점검한 기록이다. 유료상품과 AI 기능을 출시하기
전에는 전문가 검토가 필요하다.

## 현재 이용약관이 다루는 내용

- 서비스 이용 가능 연령을 만 14세 이상으로 정하고, 미성년자의 법정대리인 동의를
  언급한다.
- Apple·Google 계정 기반 가입과 사용자 콘텐츠의 권리·운영 목적 이용 허락을
  설명한다.
- 향후 정기 구독, 스토어 결제, 자동 갱신, 해지와 환불의 기본 원칙을 미리 둔다.
- 페블링은 의료 서비스·의료기기·위기 대응 서비스가 아니며 진단이나 치료를
  제공하지 않는다고 고지한다.
- 탈퇴, 분쟁·결제 관련 법정 보관, 약관 변경 고지 원칙을 설명한다.

## 현재 개인정보처리방침이 다루는 내용

- 계정 정보, 대명사, 텍스트 기록, 사진, 기기·접속·오류 정보 등을 수집 항목으로
  설명한다.
- 광고 목적 사용이나 제3자 판매를 하지 않는다고 밝힌다.
- 기록을 암호화해 운영자가 원문을 직접 볼 수 없다고 설명한다.
- Supabase, Google Firebase, Apple App Store·Google Play의 처리와 국외 이전을
  고지한다.
- 탈퇴 시 삭제, 백업 반영, 법정 보존 기간과 정보주체 권리를 설명한다.
- AI 추천 데이터와 커뮤니티 데이터는 향후 수집 가능 항목으로만 적혀 있다.

## App Store 공개 표시

- 연령 등급: `12+`
- 연결된 데이터: 이름·이메일, 사용자 ID, 사진·동영상, 고객 지원 및 기타 사용자
  콘텐츠, 제품 상호작용
- 연결되지 않은 데이터: 충돌·진단, 기기 ID와 기타 사용 데이터
- 공개 앱은 무료이며 인앱 구입 상품은 현재 확인되지 않는다.

## 출시 전에 해결할 정합성 위험

### P0 — AI 원문 처리와 공개 방침

개발 브랜치의 털어놓기 원문과 AI 결과는 기존 핵심 기록과 달리 평문 DB 컬럼을
사용하고, 원문이 OpenAI 또는 Gemini 호출에 포함되는 흐름이다. 그런데 현재
개인정보처리방침에는 해당 AI 공급자, 국외 이전 위치, 처리 목적·항목·보유 정책이
기재되어 있지 않다.

2026-07-26 `origin/dev` 코드와 최신 기획을 다시 확인한 결과는 다음과 같다.

- 최신 v1 기획은 OpenAI 단일 공급자를 사용한다. 개발 코드에는 Gemini
  어댑터가 남아 있으므로 실제 운영 설정이 OpenAI로 고정됐는지는 별도로
  확인해야 한다.
- 페블링 DB에는 사용자의 원본 기록과 사용자에게 보여줄 AI 결과가 저장된다.
- AI 생성에 사용한 원문 전체 프롬프트와 공급자의 raw 응답은 별도 제품 DB에
  복제하지 않고, 사용된 기록 ID·개수·글자 수와 모델·프롬프트·정책 버전을
  저장한다.
- 운영 OpenAI Responses 요청에는 현재 `store: false`가 명시돼 있지 않다.
- 개별 원본 기록 삭제는 `deleted_at`만 표시하고 본문은 남기는 soft delete다.
  복구기간·실제 본문 제거 시점이 정의돼 있지 않다.
- 단말의 지속 캐시에도 원문과 AI 결과가 저장되며, 앱 수준의 별도 암호화 키
  사용은 확인되지 않았다.

채택한 제품 원칙은 다음과 같다.

- 사용자 원본과 사용자에게 보여줄 AI 결과는 서비스 제공을 위해 저장한다.
- AI 요청용 원문 복사본·장기기억·임베딩은 v1에서 별도 저장하지 않는다.
- 범용 모델 학습과 공급자 데이터 공유에는 사용자 원문을 사용하지 않는다.
- 실제 사용자 원문을 내부 QA에 사용하려면 별도 안내·동의·접근·보존·삭제
  계약을 먼저 만든다.

남은 출시 결정과 구현:

- v1의 실제 OpenAI 프로젝트·모델과 데이터 공유 설정
- 운영 요청의 `store: false` 적용과 공급자 기본 보존기간 고지
- 전송되는 원문의 범위와 최소화 방식
- 로그 마스킹, DB·단말 캐시 보호와 접근 권한
- 짧은 복구기간 이후 원문 본문 제거와 결과·원문·계정 삭제 연동
- 사용자에게 언제 어떤 동의를 받을지

OpenAI API는 명시적 데이터 공유를 켜지 않는 한 입력·출력을 범용 모델 학습에
사용하지 않지만, 기본 오남용 모니터링 로그가 최대 30일 보관될 수 있다.
`store: false`와 모델 학습 금지는 같은 통제가 아니므로 각각 확인하고, 사용자에게
`어디에도 저장되지 않는다`고 안내하지 않는다.

### P0 — “모든 기록 암호화” 약속

현재 문구는 기록 전체가 암호화되고 운영자가 원문을 직접 볼 수 없다고 이해될
수 있다. 그러나 개발 중 털어놓기 원문은 평문 처리 흐름이고, 기존 사진도 비공개
저장소 사용은 확인되지만 클라이언트 측 종단간 암호화는 확인되지 않았다.

선택지는 기술을 약속에 맞추거나, 기능별 실제 보호 수준을 정확히 설명하는 것이다.
유료 AI 기능 출시 전에 반드시 하나로 맞춰야 한다.

### P0 — 연령 기준

이용약관은 만 14세 이상, App Store는 `12+`인데 실행 중 나이를 확인하거나
보호자 동의를 처리하는 흐름은 확인되지 않았다. 최신 AI 기획은
`under_18/adult/unknown`을 입력으로 고려하므로 다음을 함께 결정해야 한다.

- 실제 최소 이용 연령
- 미성년자 동의·확인 방식
- AI 결과와 안전 문구의 연령별 차이
- App Store 등급, 약관, 온보딩의 일치

### P1 — 유료상품 세부 고지

현재 약관에는 정기 구독의 일반 조항이 있지만 실제 상품은 없다. 출시 전에 다음이
제품 화면·스토어 메타데이터·약관에서 일치해야 한다.

- 상품명, 가격, 청구 주기, 무료 체험
- 무료와 유료 기능 차이 및 사용량 제한
- 자동 갱신 시점과 해지 방법
- 구매 복원, 환불 주체, 결제 실패와 권한 만료
- 초기 유료 구매자·기존 `paid_membership`의 영구 혜택

### P1 — 연락처와 사업자 표시

- 홈페이지·App Store: `pebbling@monglelabs.com`
- 약관·개인정보처리방침: `pebbling@mongloo.app`
- 홈페이지는 `Monglelabs Inc.`를, App Store는 몽글랩스를 표시한다.

두 이메일이 모두 유효할 수 있지만 사용자가 공식 창구를 혼동하지 않도록 법인명,
대표자, 사업자 정보와 개인정보 문의 창구를 일관되게 검토해야 한다.

### P1 — 분석 정보 표시

앱은 Firebase Analytics에서 사용자 ID와 제품 행동 이벤트를 사용한다. 공개
방침에는 기기·사용 정보와 광고 ID 가능성이 적혀 있다. 실제 빌드가 광고 식별자를
수집하는지 확인하고, 수집하지 않는다면 과도한 문구를 줄이며 App Store 개인정보
라벨과 실제 이벤트를 맞춰야 한다.

### P2 — 사용자 콘텐츠 이용 범위

약관은 서비스 개선·연구개발을 위한 넓은 콘텐츠 이용 허락을 둔다. AI 기능에서
원문과 결과를 품질평가·프롬프트 개선에 쓰려면 익명화 가능성만으로 추정하지 말고,
실제 이용 범위·거부권·보존 정책을 개인정보처리방침과 동의 화면에 구체화해야 한다.

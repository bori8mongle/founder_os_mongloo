# App Planning

배포된 앱, 개발 중인 기능, 아직 채택되지 않은 아이디어를 구분해 제품 결정을
기록합니다.

## 현재 작업

- [페블링 제품 컨텍스트](product-context.md): 현재 사실·결정·가설·후보·질문과
  관련 원본을 한 번에 찾기 위한 제품 판단 허브
- [유료상품 기획 기준](paid-products/README.md): 배포 제품·개발 현황·법적 고지를
  먼저 맞춘 뒤, 기존 아이디어를 유료상품 후보로 재평가하기 위한 기준 문서
- [유사 앱 결정 근거](../references/app-reference-research/index.md): 무료·유료,
  주간 리포트, 권한, AI·개인정보 질문을 결정 단위로 조사하는 OKF 묶음

## 기록 원칙

- 실제 배포 상태, 개발 중 구현, 기획 의도를 서로 다른 사실로 기록합니다.
- Figma 아이디어의 화면 완성도를 채택 여부로 해석하지 않습니다.
- 유료상품 후보는 사용자 가치, 반복 사용, 구현 비용, 안전·개인정보 위험을 함께
  검토한 뒤 채택합니다.
- 가격, 횟수 제한, 무료 체험과 같은 숫자는 근거가 확정되기 전까지 후보로 표시합니다.
- 외부 레퍼런스의 권고는 김세인이 채택하기 전까지 최종 결정으로 기록하지 않습니다.

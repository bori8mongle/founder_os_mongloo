# 속마음 실사용 시나리오 출처 원장

조사 기준일: 2026-07-28

## 공통 이용 기준

- AI Hub 데이터는 제품·서비스 연구개발 목적으로 사용할 수 있지만 데이터 권리는
  NIA와 구축 수행기관 등에 있다.
- 비식별 정보를 이용해 개인을 재식별하지 않는다.
- 각 데이터셋의 다운로드 화면과 최신 이용정책을 다운로드 직전에 다시 확인한다.
- 원본 재배포 가능 여부가 명확하지 않으므로 원문 파일을 Git·Google Sheets·외주
  인계 폴더에 넣지 않는다.
- 시나리오에는 데이터셋 번호·비식별 원본 ID·변형 버전만 남긴다.
- 공통 이용정책: [AI Hub 데이터 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105)

  - 한 사람의 여러 기록 조각으로 재작성
- 접근 조건: AI Hub 로그인·본인 인증·데이터 신청 후 다운로드
